# autofines.ge

Раз в сутки проверяет штрафы МВД Грузии по госномеру и присылает новые в Telegram
с кнопкой оплаты. Живёт на Cloudflare Workers: бесплатно, без сервера и без
репозиторной возни.

## Почему не GitHub Actions

Там cron отключается сам: «scheduled workflows are automatically disabled when no
repository activity has occurred in 60 days». Формально в документации это сказано
про публичные репозитории, но в обсуждениях сообщества на то же жалуются и
владельцы приватных — а узнать наверняка можно только пропустив проверки. Коммиты,
которые воркфлоу делает сам собой через `GITHUB_TOKEN`, активностью не считаются.

У Cloudflare Cron Triggers такого правила нет: Worker висит, пока его не удалят.
Бесплатного тарифа хватает с запасом — 100 000 запросов в сутки и 1000 записей
в KV, а мы тратим один запуск, три обращения к police.ge и одну запись в день.

Рассматривались ещё Deno Deploy (`Deno.cron` + Deno KV — рабочая альтернатива,
если Cloudflare не нравится) и PythonAnywhere, который позволил бы оставить
исходный Python; последний отпал: на бесплатном тарифе исходящие запросы идут
через белый список разрешённых сайтов, police.ge в него не входит.

## Как это работает

Источник — публичная форма [police.ge/protocol](https://police.ge/protocol/index.php?lang=en),
блок «Search by vehicle number plate». Она ищет по одному лишь госномеру, без
капчи, и под капотом дёргает `POST index.php?url=protocols/searchByAuto`
с полями `firstResult`, `protocolAuto` и `csrf_token` (токен берётся со страницы
формы, cookie той же сессии обязательна). Worker повторяет ровно этот запрос.

Ссылка на оплату собирается так же, как это делает сам сайт в функции `payment()`:
платёжный шлюз `mpi.gc.ge` с `o.protocolId` и `o.vehicleNumber`.

Отправленные протоколы запоминаются в Workers KV, поэтому одно и то же
уведомление не приходит каждый день:

| Событие | Уведомление |
|---|---|
| Появился новый протокол | 🚨 Новый штраф + кнопка «Оплатить» |
| Протокол уже присылали | молчит (либо 🔁, если `NOTIFY_ALWAYS`) |
| До конца срока оплаты ≤ `REMIND_DAYS` | ⏰ Напоминание, не чаще раза в сутки |
| Протокол пропал из базы | ✅ Скорее всего, оплачен |
| Штрафов нет | молчит (либо ✅, если `NOTIFY_EMPTY`) |
| Проверка упала | ⚠️ Текст ошибки |

Последняя строка важна: у Cloudflare нет писем о падении cron, поэтому Worker
сообщает о своих ошибках сам, в тот же чат.

## Развёртывание

1. Создать бота у [@BotFather](https://t.me/BotFather) → получить токен.
2. Написать боту любое сообщение и узнать свой chat id:
   ```sh
   curl -s "https://api.telegram.org/bot<ТОКЕН>/getUpdates" | grep -o '"chat":{"id":[-0-9]*'
   ```
3. Развернуть:
   ```sh
   npm install
   npx wrangler login
   npx wrangler kv namespace create STATE   # id из вывода → в wrangler.toml
   npx wrangler secret put PLATES             # A354OC797, можно несколько через запятую
   npx wrangler secret put TELEGRAM_BOT_TOKEN
   npx wrangler secret put TELEGRAM_CHAT_ID
   npx wrangler secret put TRIGGER_SECRET     # необязательно — пароль к ручному запуску
   npx wrangler deploy
   ```
4. Проверить, что сообщение доходит:
   ```sh
   curl "https://autofines-ge.<ваш-поддомен>.workers.dev/run?key=<TRIGGER_SECRET>"
   ```
   Добавьте `&always=1`, чтобы прислало и уже известные штрафы.

Если публичный URL не нужен вовсе, поставьте `workers_dev = false` в `wrangler.toml` —
cron продолжит работать, а ручка `/run` просто исчезнет.

## Настройки

Секреты (`wrangler secret put`): `PLATES`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`,
`TRIGGER_SECRET`. Остальное — блок `[vars]` в `wrangler.toml`:

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `PLATES` | — | Госномера через запятую. Латиница слитно, без пробелов и кода страны |
| `REMIND_DAYS` | `7` | Напоминать за столько дней до конца срока оплаты; `0` — не напоминать |
| `NOTIFY_ALWAYS` | `0` | Слать все текущие штрафы каждый запуск, а не только новые |
| `NOTIFY_EMPTY` | `0` | Присылать «штрафов нет» — пульс, что проверка живая |
| `TRIGGER_SECRET` | — | Пароль к `/run`. Не задан — ручка отдаёт 404 всем |

Расписание — `crons` в `wrangler.toml`, время в UTC.

## Разработка

```sh
npm test                       # 16 тестов: логика уведомлений и весь проход с подменённым fetch
npm run live -- A354OC797      # живой запрос к police.ge, без Telegram и без записи состояния
npm run dev                    # Worker в локальном workerd; переменные берутся из .dev.vars
```

Для `npm run dev` скопируйте `.dev.vars.example` в `.dev.vars` и подставьте свои
значения; файл в `.gitignore`.

## Что стоит иметь в виду

- **Доступность police.ge из Cloudflare.** Сервис известен придирчивостью к
  не-грузинским IP. С этой машины и из локального workerd он отвечает, но как он
  смотрит на адреса Cloudflare — покажет первый запуск через `/run`. Если начнёт
  отваливаться, придёт ⚠️ в тот же чат.
- **Только штрафы МВД.** Парковка Тбилиси и Батуми, а также экологический надзор
  сюда не попадают: они живут на [protocols.ge](https://protocols.ge) и
  [parking.tbilisi.gov.ge](https://parking.tbilisi.gov.ge) за reCAPTCHA v3.
  У тбилисской парковки есть штатная SMS-подписка по номеру авто — это
  официальный способ получать оттуда уведомления.
- **Статьи по-грузински.** Словарь `ARTICLES` в `src/notify.js` переводит те коды,
  что уже встречались; незнакомый код уходит в сообщение как есть, оттуда его и
  можно добавить в словарь.
